COMMANDS CHEAT SHEET
====================

1. Initial Setup (one-time):
   cd Flask
   
   Windows: setup.bat
   Linux/Mac: bash setup.sh

2. Preprocess Images (10 min):
   python preprocess_dataset.py

3. Train Models (2-4 hours):
   python train_models.py

4. Generate Grad-CAM Heatmaps (for report):
   python gradcam.py

5. Start Flask Server (Terminal 1):
   python app.py
   
   Expected: "Starting Flask server on localhost:5000"

6. Start ngrok Tunnel (Terminal 2):
   ngrok http 5000
   
   Copy output URL: https://xxxxxx.ngrok.app

7. Update Flutter (replace in api_service.dart):
   static const String flaskBaseUrl = 'https://xxxxxx.ngrok.app';

8. Run Flutter App:
   cd agrosetu_app
   flutter run

NGROK NOTES
===========

Free plan limitations:
- URL changes every time you restart ngrok (2 hour expiration)
- Need to update Flutter app with new URL each time
- Max ~40 requests/min

When ngrok expires or you restart:
1. Kill ngrok (Ctrl+C in ngrok terminal)
2. Run: ngrok http 5000
3. Copy new URL
4. Update api_service.dart with new URL
5. Recompile Flutter app

For production, deploy Flask to cloud service instead

COMMON ERRORS & FIXES
====================

"ModuleNotFoundError: No module named 'tensorflow'"
→ pip install tensorflow

"Could not find models/mobilenet_scratch.h5"
→ Run train_models.py first

"Network error: Flask server not running"
→ Check Flask is running: python app.py
→ Check port 5000 is not blocked by firewall

"ngrok URL not accessible"
→ Verify Flask is actually running (should see output in terminal)
→ Check ngrok URL is current (expires after 2 hours)
→ Make sure device has internet connection

Model training very slow or stuck:
→ Use GPU if available (NVIDIA with CUDA)
→ Reduce batch size in train_models.py: BATCH_SIZE = 16
→ Use Google Colab instead (free GPU)

WHAT EACH COMPONENT DOES
========================

preprocess_dataset.py:
- Reads raw dataset from archive/idata/
- Resizes all images to 224x224
- Organizes into train/valid splits
- Validates image integrity

train_models.py:
- Builds 3 different architectures
- Trains each model from scratch (no pretrained weights)
- Applies data augmentation
- Saves weights as .h5 files
- Logs training metrics

gradcam.py:
- Generates heatmap visualizations
- Shows where models focus when predicting
- Proves models learned leaf patterns, not just backgrounds
- Creates evidence for your report

app.py (Flask):
- Loads all 3 trained models
- Accepts image uploads via POST /predict
- Runs ensemble voting (average predictions)
- Looks up disease solutions from JSON
- Returns JSON with disease, confidence, treatment

api_service.dart (Flutter):
- Sends images to Flask server
- Parses JSON response
- Handles network errors
- Manages timeouts

disease_detection_page_new.dart (Flutter):
- UI for image capture/gallery
- Displays results to user
- Shows treatment recommendations
- Logs activities
